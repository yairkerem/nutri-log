# יומן תזונה ואימונים

אפליקציית ווב לתיעוד כל מה שנאכל וכל אימון, בעברית, עם הכתבה קולית. כל רשומה נשמרת עם חותמת זמן מלאה, כדי שאפשר יהיה לנתח את הנתונים בהמשך.

**היומן חי בכתובת <https://yairkerem.github.io/diet-diary/>** — כתובת https, ולכן ההכתבה עובדת שם גם בטלפון. הדף אינו מופיע במנועי חיפוש (`noindex, nofollow`).

אין שרת, אין התקנה ואין תלויות: HTML, CSS ו-JavaScript בלבד. הנתונים נשמרים ב-`localStorage` של הדפדפן — כלומר בנפרד לכל מכשיר ולכל דפדפן.

## הפעלה מקומית

הכתבה קולית בדפדפן מותרת רק מדף שנטען מ-`localhost` או מ-`https`. לכן יש שתי דרכים:

- **עם הכתבה** – הרצת השרת המקומי (PowerShell, בלי התקנות):

  ```bash
  powershell -ExecutionPolicy Bypass -File tools\serve.ps1
  ```

  ואז פתיחת <http://localhost:8123> בדפדפן. `Ctrl+C` עוצר את השרת. אפשר לבחור פורט אחר עם `-Port 8124`.

- **בלי הכתבה** – פתיחה ישירה של `index.html` בדפדפן. הכול עובד חוץ מהמיקרופון, וכפתור המיקרופון יסביר זאת.

להכתבה נדרש Chrome או Edge (ה-Web Speech API אינו נתמך בכל הדפדפנים). בפעם הראשונה הדפדפן יבקש הרשאת מיקרופון.

## איך משתמשים

כותבים או מכתיבים משפט חופשי, והאפליקציה מפרקת אותו לרשומות:

| מה שאומרים | מה שנשמר |
| --- | --- |
| `אכלתי 2 פרוסות לחם עם אבוקדו` | אוכל · לחם עם אבוקדו · 2 פרוסות |
| `שתיתי 250 מ"ל קפה עם חלב בשעה 8:15` | אוכל · קפה עם חלב · 250 מ"ל · בשעה 8:15 |
| `רצתי 5 ק"מ ב-32 דקות` | אימון · ריצה · 32 דקות · 5 ק"מ |
| `חדר כושר שעה וחצי, 3 סטים של 12 חזרות` | שתי רשומות אימון |
| `אתמול בערב אכלתי חצי מנה פסטה` | אוכל · פסטה · 0.5 מנה · אתמול ב-20:00 |

מה שמזוהה אוטומטית:

- **כמויות** – ספרות (`100`, `1.5`) ומילים (`חצי`, `שתי`, `עשרה`), יחד עם יחידות: גרם, ק"ג, מ"ל, ליטר, כוס, כף, כפית, פרוסה, מנה, קופסה, חופן ועוד.
- **אימונים** – ריצה, הליכה, אופניים, שחייה, חדר כושר, יוגה ועוד, כולל דקות, שעות, ק"מ, צעדים, סטים וחזרות ועצימות.
- **זמן** – `בשעה 8:15`, `ב-8 בבוקר`, `לפני שעתיים`, `אתמול`, `שלשום`, `בבוקר` / `בצהריים` / `בערב` / `בלילה`. בלי ציון זמן נשמרת שעת ההקלדה.
- **הפרדה בין פריטים** – פסיק, `וגם`, `ועוד`, `ואז`, `בנוסף`.

### כשחסרה כמות

רשומה בלי כמות (אוכל) או בלי מאמץ (אימון) לא נשמרת בשקט: היא עולה לאזור **השלמת פרטים** עם שאלה מפורשת ("כמה גלידה וניל?"), שדה כמות מודגש, קיצורי כמויות נפוצות, ואפשרות לתקן את השעה או את סוג הרשומה. משם אפשר **לשמור**, **לשמור ללא כמות** או **להסיר**. רשומה שכבר כוללת כמות נשמרת מיד.

### היומן

הרשומות מקובצות לפי יום, עם שעה לכל אחת. אפשר לסנן לפי סוג, לחפש בטקסט, לבחור טווח (היום / 7 ימים / 30 ימים / הכל), וללחוץ על רשומה כדי לערוך כל שדה — כולל התאריך והשעה — או למחוק אותה.

## גיבוי וניתוח

בתפריט `⋯` שבראש הדף.

**שיתוף וייצוא** – לשליחה לדיאטנית, למאמן או לרופא. בוחרים טווח (7 / 14 / 30 הימים האחרונים, הכל, או טווח מותאם עם תאריך התחלה וסיום), והשורה שמתחת מראה כמה רשומות ייכללו:

- **שיתוף הקובץ** – פותח את תפריט השיתוף של המכשיר ושולח את ה-CSV ישירות לוואטסאפ, למייל או לכל יישום אחר, בלי לרדת קודם למכשיר. דורש דפדפן שתומך בשיתוף קבצים (Chrome בטלפון); בדפדפן שאינו תומך הכפתור מושבת והסבר מופיע לידו.
- **ייצוא CSV** – מוריד את אותו קובץ, בשם `diet-diary-<מתאריך>_<עד תאריך>.csv`. הקובץ נושא BOM ולכן נפתח נכון ב-Excel, ועמודותיו: מזהה, חותמת זמן (ISO), תאריך, שעה, יום בשבוע, סוג, שם, כמות, יחידה, ארוחה, קלוריות, דקות, ק"מ, צעדים, סטים, חזרות, עצימות, הערה, טקסט מקורי ומקור (הקלדה או הכתבה). השורות מסודרות כרונולוגית.

**גיבוי מלא** – כולל תמיד את כל הרשומות, בלי קשר לטווח שנבחר:

- **ייצוא JSON** – גיבוי, וגם הדרך להעביר רשומות בין מכשירים.
- **ייבוא JSON** – מוסיף רשומות מקובץ גיבוי ומדלג על מזהים שכבר קיימים.
- **מחיקת כל הרשומות**.

הנתונים נשמרים רק בדפדפן הזה ובמכשיר הזה. ניקוי נתוני הדפדפן מוחק אותם, ולכן כדאי לייצא מדי פעם.

## מבנה הקוד

```
index.html          שלד הדף והדיאלוגים
css/style.css       עיצוב, RTL, מצב כהה ומסכי טלפון
js/lexicon.js       מילון עברי: מספרים, יחידות, פעילויות, ארוחות
js/parse.js         פירוק הטקסט לרשומות (כמות, זמן, סוג, שם)
js/store.js         שמירה ב-localStorage, שאילתות, ייצוא וייבוא
js/speech.js        הכתבה קולית (Web Speech API, he-IL)
js/ui.js            בניית התצוגה
js/app.js           חיווט האירועים
tools/serve.ps1     שרת סטטי מקומי
test/parser-test.html  בדיקות לניתוח הטקסט
```

## פרסום

דחיפה ל-`main` מפרסמת מחדש את האתר ב-GitHub Pages. השירות שומר קבצים במטמון לעשר דקות, ולכן `index.html` טוען את ה-CSS וה-JS עם `?v=N` — יש להעלות את `N` בכל שינוי ב-CSS או ב-JS, אחרת מבקרים חוזרים יקבלו גרסה ישנה (`v=1` נכון לפרסום הראשון).

## בדיקות

פתיחת <http://localhost:8123/test/parser-test.html> מריצה את בדיקות הניתוח ומציגה "עברו N מתוך M בדיקות" יחד עם פירוט לכל מקרה. כדאי להוסיף שם מקרה בדיקה לכל ניסוח חדש שהמנתח מפספס.
